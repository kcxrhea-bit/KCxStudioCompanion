# Who KCx Studio Companion Is For

## Primary Audience

- Solo developers building Android, Electron, or web apps.
- AI-assisted developers using tools like Codex, Gemini, Ollama, OpenAI-style APIs, or manual prompt handoff.
- Indie builders iterating on prototypes with frequent build/test/fix cycles.
- Android/Kotlin developers dealing with Gradle, Room, KSP, Compose, or manifest errors.
- Electron/React developers working with Vite, TypeScript, npm, and desktop packaging.
- Developers who want local-first workflow memory without a forced cloud dependency.

## Good Use Cases

- Parse a build failure and turn it into a focused fix prompt.
- Keep project safety rules visible while using AI coding tools.
- Track fix, validation, and regression prompts as a chain.
- Review AI-generated patch summaries for broad rewrite or architecture risk.
- Queue and approve local commands instead of executing them silently.
- Preserve project memory across multiple coding sessions.

## Who It Is Not For Yet

- Enterprise teams needing collaboration, permissions, SSO, or shared cloud state.
- Non-developers with no build logs, source projects, or IDE workflow.
- CI/CD pipeline automation.
- Users expecting fully autonomous code changes.
- Public production buyers expecting signed installers, auto-update, and professional support.

## Current Beta Fit

Best fit for private beta: technically comfortable Windows 10/11 users who understand build logs, local file paths, and manual AI prompt workflows.
