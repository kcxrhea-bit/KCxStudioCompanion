# What KCx Studio Companion Does

KCx Studio Companion is a local-first AI-assisted development orchestration platform for iterative software workflows.

It helps a developer keep build logs, project memory, prompt chains, patch review, provider routing, and command approvals organized while working with AI tools.

## Core Capabilities

- **Build analysis**: Parses Gradle, Kotlin, npm, Vite, Electron, and TypeScript-style logs with heuristic extraction.
- **Prompt orchestration**: Generates fix, validation, and regression prompt chains from build failures.
- **Project memory**: Tracks project goals, important files, protected files, and workflow notes.
- **Build history**: Stores analyzed build records per project.
- **Command approval**: Routes command execution through a human approval queue.
- **Patch review**: Flags risky patch language, affected files, and recommended validation steps.
- **Provider routing foundation**: Models local and cloud provider routing while keeping cloud providers optional.
- **Session timeline**: Records build analysis, prompt generation, command execution, scan, and review events.
- **Local diagnostics**: Stores local runtime logs for troubleshooting.

## What It Is Not

- **Not autonomous coding**: You review and approve actions.
- **Not AGI**: It is workflow software, not sentient or self-directed intelligence.
- **Not cloud-dependent**: Local workflows work without a required cloud account.
- **Not a replacement for your IDE**: It complements VS Code, Android Studio, terminals, and AI coding tools.
- **Not a guarantee of correctness**: Parser output and AI suggestions require developer judgment.

## Target Users

KCx Studio Companion is currently aimed at solo developers, indie builders, and AI-assisted developers working with Android/Kotlin, Electron, React, TypeScript, Vite, npm, or similar stacks.
