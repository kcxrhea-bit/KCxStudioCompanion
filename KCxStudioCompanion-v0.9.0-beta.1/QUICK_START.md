# Quick Start

1. Open KCx Studio Companion.
2. Add a project with a name, local path, project type, and goal.
3. Use Project Context to scan the folder.
4. Paste or run build logs from Build Logs.
5. Generate fix, validation, or regression prompts from analyzed failures.
6. Review prompt and command approvals before sending or executing.
7. Use Project Memory to mark protected files and do-not-rewrite rules.
